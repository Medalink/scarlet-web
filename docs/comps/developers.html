API

Everything public on this site is readable as JSON with an API key. Read-only, version 1.

Using the API

The base is https://<host>/api/v1/public. Answers are JSON in UTF-8. Times are ISO 8601 in UTC, durations are seconds, money is copper. Any origin may call it from a browser. Answers can be cached for five minutes and carry an ETag.

curl https://<host>/api/v1/public/stats?ruleset=3

Limits and keys

Sign in with Battle.net and make a key on your account page. It expires after 30 days by default, 90 at most. Send it as Authorization: Bearer <key>. 600 requests a minute per account. Over the limit the answer is 429 with Retry-After.

Pagination

Lists return data and next_cursor. Pass it back as ?cursor=. A null cursor is the end. Numbers a bucket cannot show because too few characters contributed come back as null.
